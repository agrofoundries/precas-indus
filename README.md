# PET Digital Growth Agency - Enterprise Next.js Platform

A visual-first digital marketing agency homepage built with Next.js 14+ (App Router), React 18+, Tailwind CSS, Framer Motion, and Lucide React icons.

## 🚀 Key Features & Agency Capabilities

* **Sticky Glassmorphic Navigation Bar**: Brand logo integration (`/images/PET_Blue.png`), animated navigation tab underlines, and interactive "Schedule Executive Briefing" modal CTA.
* **High-Impact Hero Section**: Headline, low-copy subtitle, dual CTAs, and interactive live analytics dashboard graph mockup.
* **Enterprise Client & Tech Marquee**: Ticker showcasing Fortune 500 partners and core agency technologies.
* **Full-Service Digital Agency Matrix**:
  * **Search Engine Optimization (SEO)**: Technical Core Web Vitals, Page 1 Google Rankings, Keyword Authority.
  * **Custom Website Engineering**: Next.js 14+ App Router, Sub-100ms Load Times, Responsive UI/UX.
  * **Performance PPC & Paid Media**: Google Search Ads, B2B LinkedIn Marketing, Meta Video Ads.
  * **Conversion Rate Optimization (CRO)**: Friction Heatmaps, Multivariate A/B Testing.
  * **Lifecycle Email & SMS Automation**: Klaviyo & HubSpot Drip Workflows, Retention Scaling.
  * **Marketing Data Analytics**: GA4 Setup, Multi-Touch Attribution, CRM Closed-Loop Sync.
* **Technologies & Frameworks Showcase**: Official SVG logos for WordPress, PHP, Laravel, Node.js, React, Next.js, Vue, Shopify, Tailwind CSS, TypeScript, and Marketing suites.
* **Strategic Capabilities Bento Grid**: Visual previews for Performance Architecture, Brand Systems, Full-Funnel Automation, and Closed-Loop Analytics.
* **Portfolio Showcase & Agency Layouts**: Interactive case study modals featuring real web engineering deliverables.
* **Execution Quality Standards**: 100% Custom Code, SEO Speed Scores, 14-Day Sprint Velocity.
* **Proprietary 4-Phase Growth Framework**: Step-by-step horizontal visual timeline (`01 Discover` → `02 Architect` → `03 Execute` → `04 Scale`).
* **Executive Endorsements & Proof**: Multi-column verified review cards with industry filters.
* **Interactive Strategy Cost & Scope Calculator**: Dynamic budget slider modeling squad allocation and recommended sprint scope.
* **Modern High-Conversion Consultation Footer**: Embedded consultation booking bar, logo, SOC2 compliance badge, legal links, and corporate office locations (New York / San Francisco).

## 🛠️ Technology Stack

* **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
* **Library**: [React 19+](https://react.dev/)
* **Styling**: [Tailwind CSS 3.4+](https://tailwindcss.com/)
* **Animations**: [Framer Motion 12+](https://framer.com/motion)
* **Icons**: [Lucide React](https://lucide.dev/)
* **Language**: [TypeScript 5+](https://www.typescriptlang.org/)

## 🚦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/shantanukumar2026/precas-indus.git
   cd precas-indus/bkp
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)

## 📦 Build for Production

```bash
npm run build
npm run start
```
